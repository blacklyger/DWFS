DWFS

Don't wanna wait for files and stuff


DWFS ist eine für Lehrer und Schüler entwickelte file sharing und hosting Platform. Ich empfand es für nötig diese Platform zu entwickeln, da Downloads von unserem bestehenden System (IServ) sehr lange dauern.
Doch dieses Problem gehört mit diesem System ab sofort der Vergangenheit an!

So funktioniert es ...


Schritt 1.

Melden Sie sich mit ihren Anmeldedaten an.

Schritt 2.

Suchen Sie sich das Fach aus, für das Sie Dateien hochladen wollen.

Schritt 3.

Laden Sie eine oder mehrere Datei/en für das Fach hoch.

Schritt 4.

Kopieren Sie den generierten Downloadlink aus der Übersicht. Mit diesem Link lässt sich die ausgewählte Datei herunterladen.
